Steam 多账号拥有检查 · 设置

1. 添加账号

先在浏览器里登录 store.steampowered.com，再点导入。这个方式不需要 API key、也不要求档案公开， 但一次只能导入"当前登录的那一个"账号 —— 多账号玩家请依次登录每个账号各导入一次。
档案的「游戏详情」必须是公开的，否则 API / 公开档案都读不到库。私密档案请用上面的登录态导入。

2. 我的账号

    3. 共享 API key

    在 steamcommunity.com/dev/apikey 免费申请。一个 key 可以用来查询任意「游戏详情公开」的账号，所以多个账号通常只需要一个 key。 key 只保存在本机（chrome.storage.local），只会发往 api.steampowered.com。

    4. 显示与刷新

    （只有配置了 API key 的账号能后台刷新；登录态导入的账号需要你手动点刷新）

    5. 诊断（怀疑抓错数据时用）

    依次读取：① 商店页面里的会话身份（SteamID / token）② dynamicstore 许可证条目 ③ 用会话 token 调 GetOwnedGames（真正的游戏列表）④ 许可证页面 ⑤ 本地记录与索引， 并逐项标出条数、数据里的 steamid、以及**是否包含目标 AppID**。 如果抓到的数据不属于当前账号，这几项会互相矛盾，一眼就能看出来。

        导出文件可以直接导入到手机版页面（mobile/index.html），这样手机上也能离线查"哪个账号有这款游戏"。
        「下载为文件」会存成 steam-multi-owner.json，便于喂给 DSH 插件：
        steam_owner_data action=import file=<文件路径>。
      
    
      
    
      
      
    
    
    

    
    
      
    隐私说明
    
      
    
        · 所有数据（账号列表、库快照、索引）都只保存在你本机的 chrome.storage.local，不上传任何服务器。
    
        · 扩展只访问 3 个域名：api.steampowered.com、store.steampowered.com、steamcommunity.com。
    
        · 没有任何统计、埋点、第三方请求；没有远程代码。
    
        · API key 不随导出文件外泄。
